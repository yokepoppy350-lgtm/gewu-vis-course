# 格物 · 可视化导论

《可视化导论》课程网站重构作业。原课程：https://cinger007.github.io/vis/ 。本作品是学生学习站，不是学校官方站点。

## 运行与发布

无需安装前端依赖。将全部文件放在同一目录，可直接打开 index.html（推荐 HTTP 服务以支持剪贴板等浏览器功能）：

```sh
python -m http.server 8765
```

浏览器访问 http://localhost:8765 。GitHub Pages 选择 main 分支根目录发布。路由使用 hash，刷新章节链接不会产生 404。

## 结构与功能

- `index.html`：语义化外壳、导航、桌宠。
- `style.css`：近白纸色、炭灰、低饱和灰绿与像素细节；响应式布局及减少动态效果支持。
- `lessons.js`：五章独立撰写的知识要点、代码模式和自测；各章另配学习目标、核心定义表及公式/例子。
- `app.js`：路由、实验、持久化、Markdown/SVG 导出和桌宠交互。
- `assets/`：本地 D3 7.9.0、像素素材、原创猫 SVG 与许可。

五章沿用原课程的数据、流程、色彩、低维和时序结构。要点重组为概念/代码/实验三标签，并链接教师完整讲义，不声称代替原讲义所有细节与推导。原课程含有的模型生成数据案例改为固定手工教学数据，无真实个人信息。

实验：类别条形图的指标与排序、流程步骤追踪、三类色板、散点图坐标与回归、时序平滑与日历热图。所有数值实验提供数据表与解释。适用实验支持 SVG 下载。

本地学习记录使用 localStorage 键 `gewu-v1`：完成章节、答对自测、章节笔记、桌宠显示偏好。不发往服务器。跨设备不同步；清理浏览器或隐私模式可能丢失，笔记可导出 Markdown。桌宠可以拖动，也可用方向键移动、回车互动；支持喂食、提示、休息、隐藏及恢复。

## 教程与素材选择原则

优先采用 2025—2026 年发布的官方教程、当前官方 API 文档，以及作者官网明示 2026 年发布的素材。页面公布的发布日期、更新日期与本次核验日期分别标注，不把抓取日期当成更新日期。不声称列出了全网最新资料。

具体来源、时间与许可见 SOURCES.md 和网站“参考书架”。图表实现使用 D3，Plot 教程只作为图表选型与数据组织的延伸阅读，不混淆 API。

网站没有视频或音频资源；演示视频为独立提交附件。没有统计脚本、登录或聊天服务。

## 许可与署名

自写页面、教材要点、示例数据与原创图形用于本次课程作业。第三方代码和素材保留各自许可：D3（ISC），Kenney Tiny Farm（CC0）。原教师讲义只链接、不复制完整内容。无转载官方教程全文或未授权照片。

## 排版与文本

参考 MIT OpenCourseWare、D3 官方与 MDN 的资料组织方式。使用系统无衬线字体和等宽代码字体，统一标题层级；学习内容优先展示定义、条件、公式、示例与常见误区。首页使用课程目标和先修要求，不以文学化宣传文案占据主要区域。
