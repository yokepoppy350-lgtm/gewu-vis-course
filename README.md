# VIS—05 · 可视化导论

《可视化导论》课程网站重构作业。原课程：https://cinger007.github.io/vis/ 。本作品是学生学习站，不是学校官方站点。

## 运行与发布

无需安装前端依赖。将全部文件放在同一目录，可直接打开 index.html（推荐 HTTP 服务以支持剪贴板等浏览器功能）：

```sh
python -m http.server 8765
```

浏览器访问 http://localhost:8765 。GitHub Pages 选择 main 分支根目录发布。路由使用 hash，刷新章节链接不会产生 404。

## 结构与功能

- `index.html`：页顶导航、进度和课程外壳。
- `style.css`：独立设计的像素实验讲义版式，直角与硬边反馈。
- `lessons.js`：五章知识讲解、关键代码与自测。
- `app.js`：首页单位图、五组实验、路由、笔记持久化和 SVG/Markdown 导出。
- `DESIGN.md`：这次设计修订的依据、颜色角色、排版与取舍。
- `SOURCES.md`：教程和参考资料的日期、作者与许可。

打开网站默认进入课程目录，主导航第一项也是课程目录。五章以带编号、知识点和明确阅读入口的列表呈现，右侧解释学习步骤。单位图和条形图保留在“编码示例”页。宠物功能已删除。章节仍采用“目标、定义、公式与例子、分节讲解、代码、实验、自测”的知识结构。

五章沿用原课程的数据、流程、色彩、低维和时序结构，不声称替代原始讲义的所有推导。理论扩展通过“教师完整讲义”入口阅读。所有数据均为固定手工教学示例。

本地记录键仍为 `gewu-v1`，只保存完成章节、自测状态、章节笔记与最后阅读章节。旧记录中的其他字段不会保留。记录不上传、不跨设备同步，浏览器清理可能导致丢失，请导出笔记留存。

界面资源全部本地加载。当前页面使用 D3 7.9.0（ISC）、原创 SVG 点阵标识与数据图，没有嵌入视频、统计脚本或账户系统。assets 中旧版未引用素材仅用于版本追溯，不属于当前页面功能。
